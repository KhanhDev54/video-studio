# Nhân vật mẫu

Bộ hình đơn giản để thử tính năng nói khớp miệng (tab Hoạt hình → Nhân vật nói). Thay bằng nhân vật bạn tự vẽ theo cùng cách đặt tên:

| File | Nội dung |
|---|---|
| `body.png` | Thân + mặt, **không vẽ miệng** (bắt buộc) |
| `mouth_X.png` | Miệng nghỉ, khép |
| `mouth_A.png` | Mím môi (m, b, p) |
| `mouth_B.png` | Hé răng (hầu hết phụ âm) |
| `mouth_C.png` | Mở vừa (e, a ngắn) |
| `mouth_D.png` | Mở to (a) |
| `mouth_E.png` | Tròn (o) |
| `mouth_F.png` | Chu môi (u, w) |
| `mouth_G.png` | Răng trên chạm môi dưới (ph, v) |
| `mouth_H.png` | Thấy lưỡi (l) |
| `blink.png` | Mắt nhắm, phủ lên khi chớp mắt (không bắt buộc) |

Mọi file là PNG nền trong suốt, **cùng kích thước**, vẽ đúng vị trí trên cùng một khung (app chồng chúng tại góc trên trái). Chỉ cần tối thiểu `body.png` và 2 hình miệng; hình thiếu sẽ được thay bằng hình gần nhất. Bộ mẫu này có X, B, C, D.

Tên khẩu hình theo chuẩn của [Rhubarb Lip Sync](https://github.com/DanielSWolf/rhubarb-lip-sync).
